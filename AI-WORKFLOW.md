# AI Workflow & Transparency

## Tools Used
- **Agentic AI Assistant (Antigravity)**: Primarily utilized for generating React UI components, enforcing backend business logic across Express controllers, and debugging cross-stack errors.

## What Was Delegated vs. Written
- **Delegated to AI**: Heavy lifting on Tailwind CSS layout generation, boilerplate Express routing, and setting up the basic React Flow topology components.
- **Handled Manually / Heavily Guided**: The specific physical logic for localizing the fault (DFS traversal), the schema representation of the power grid, and the strict adherence to the simulated telemetry business logic. AI struggles with highly niche physical domains without extensive guidance.

## Where AI Was Wrong (and How We Caught It)
1. **Missing Buttons**: The AI originally rewrote the `FaultSimulator.jsx` UI and accidentally deleted the "Restore Network" button entirely, breaking the verification lifecycle. I caught this by running the E2E lifecycle and noticing I was indefinitely stuck in the `RESOLVED` state because I couldn't inject the `power_on` telemetry.
2. **Infinite React Render Loop**: When the AI generated the `TopologyFlow` map, it passed an unmemoized array dependency into `useEffect` causing the frontend to blink out of control and lock up the browser. I diagnosed the terminal crash and injected a `useMemo` wrapper to stabilize the render tree.
3. **Mongoose Enum Validation**: The AI created backend simulated incidents with a status of `"Open"`, but simultaneously rewrote the Mongoose schema to strictly require `"DETECTED"`. The UI buttons subsequently failed to appear because the status strings mismatched. I wrote a manual MongoDB `updateMany` script to backfill legacy data.

## Code Proportion
Approximately 75% of the raw lines of code (primarily boilerplate, CSS, and basic routing) were generated by AI, but 100% of the core architectural decisions (DFS graph logic, ticket automated transitions, schema design) were heavily intervened upon to meet the specific requirements of the prompt.
